# TDD Rule

> **이 규칙은 Rigid다. 상황에 맞게 변형하지 마라.**
> 예외는 아래 "적용하지 않는 대상"에 적힌 것뿐이다. 그 외의 판단은 하지 않는다.

## 0. 우선순위

- 프로젝트의 `CLAUDE.md` 또는 `AGENTS.md`에 TDD 규칙이 있으면 **그 규칙이 우선**한다.
- 이 파일은 프로젝트 규칙이 없을 때 쓰는 **기본값(fallback)** 이다.

## 1. 적용 기준

### 반드시 적용

- **비즈니스 로직**: 도메인 규칙, 상태 전이, 계산, 검증
- **API**: 엔드포인트 핸들러, 요청과 응답 변환, 에러 응답
- **유틸 함수**: 파싱, 포맷팅, 변환, 헬퍼
- **버그 수정**: 버그를 재현하는 실패 테스트를 먼저 쓴다

### 적용하지 않는 대상

- **타입 정의**: interface, type, enum, 스키마 선언
- **설정 파일**: `*.config.*`, `tsconfig`, `.env.example`, CI 설정
- **순수 UI**: 로직 없이 props를 그려 주기만 하는 마크업과 스타일
- **SQL**: 마이그레이션, 단순 쿼리 문자열

판단 기준은 하나다. **분기나 계산이 있으면 적용한다.** 없으면 적용하지 않는다.

## 2. RED-GREEN-REFACTOR 사이클

### RED

- **하나의 동작 = 하나의 테스트**. 한 테스트에 여러 동작을 넣지 않는다.
- 테스트를 **반드시 실행해서 실패를 확인**한다. 실행하지 않은 RED는 RED가 아니다.
- 실패 이유는 **"기능 미구현"** 이어야 한다. 문법 오류, import 오류, 오타로 실패한 것은 RED로 치지 않는다. 고치고 다시 실행한다.
- 테스트 이름은 동작을 서술한다. 예: `빈 프롬프트를 보내면 400을 반환한다`

### GREEN

- 그 테스트를 통과시키는 **최소한의 코드만** 쓴다. 하드코딩도 허용한다.
- **YAGNI**. 다음 테스트가 요구하기 전에는 일반화, 옵션, 확장점을 넣지 않는다.
- **신규 테스트와 기존 테스트 전체**를 실행해 모두 통과하는지 확인한다.
- 기존 테스트가 깨지면 GREEN이 아니다. 먼저 되돌린다.

### REFACTOR

- 허용: **중복 제거, 이름 개선, 헬퍼 추출**, 구조 정리
- 매 변경 후 테스트를 실행해 **green을 유지**한다.
- **새 동작 추가 금지**. 동작이 바뀌면 리팩토링이 아니다. 새 RED로 간다.
- 테스트 코드도 같은 기준으로 정리한다.

### 반복

- 다음 동작 하나를 고르고 **RED로 돌아간다**.
- 사이클 하나는 몇 분 안에 끝나야 한다. 길어지면 동작을 더 작게 쪼갠다.

## 3. 삭제 강제 규칙

- 테스트보다 **프로덕션 코드를 먼저 작성했다면 그 코드를 삭제**하고 RED부터 다시 시작한다.
- 주석 처리, 다른 파일로 이동, "참고용"으로 남기기 **모두 금지**한다. 삭제한다.
- 이유: 먼저 쓴 코드가 남아 있으면 테스트가 그 코드에 맞춰 쓰인다. 그 테스트는 동작이 아니라 구현을 검증한다.

## 4. 변명 차단표

| 변명 | 반론 |
|------|------|
| **"너무 단순해서 테스트가 불필요하다"** | 단순하면 테스트도 단순하다. 1분이면 쓴다. 단순한 코드가 깨졌을 때 찾는 비용이 더 크다. |
| **"나중에 추가하겠다"** | 나중은 오지 않는다. 지금 쓰지 않은 테스트는 구현에 맞춘 테스트가 되거나 영영 없다. |
| **"시간이 없다"** | TDD는 디버깅 시간을 앞당겨 쓰는 것이다. 테스트 없이 짠 코드의 디버깅 시간이 더 길다. |
| **"삭제하면 낭비다"** | 이미 쓴 코드는 매몰 비용이다. 다시 쓰면 더 빨리, 더 작게 쓴다. 남기면 테스트가 오염된다. |
| **"프로토타입이다"** | 프로토타입은 거의 항상 프로덕션이 된다. 버릴 코드라면 테스트도 같이 버리면 된다. 비용은 같다. |

## 5. 완료 조건

다음을 모두 보여 줄 수 있어야 완료다.

- RED 단계의 **실패 출력**
- GREEN 단계의 **전체 테스트 통과 출력**
- REFACTOR 후의 **전체 테스트 통과 출력**

출력 없이 "테스트했다"고 말하지 않는다.
